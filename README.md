1. ゲーム概要
	本作はPvE形式のFPSシューティングゲームです。
	1Wave30秒で進行し、最後まで生き残ることでWaveクリアとなります。
	Waveクリアごとにランダムに選ばれた3つのバフを選択し、プレイヤーを強化できます。
	また、バフの獲得以外に、敵を倒すことで経験値を獲得してレベルアップすることでステータスを強化できます。
	ゲームに明確な終了はなく、どこまでWaveを進め、スコアを獲得できたかを競います。

2. プレイ方法	
	キーボード&マウスの場合
		移動: W,A,S,D
		ダッシュ: Shift
		ジャンプ: Space
		リロード: R
		射撃モード変更: B
		射撃: 左クリック
		一時停止: Tab
		メニュー操作 : W,S,↑,↓
		メニュー決定 : F,左クリック

	コントローラーの場合(※ボタン表記は DualShock4(PS4コントローラー)に基づいています。)
		移動: 左スティック
		ダッシュ: R1
		ジャンプ: ×
		リロード: □
		射撃モード変更: L1
		射撃: R2
		一時停止: Options
		メニュー操作 : ↑,↓
		メニュー決定 : ×

3. 起動方法
	1. 「実行ファイル」フォルダを選択して開きます。
	2. 「実行ファイル」フォルダ内の「ASCEND.exe」をダブルクリックして起動します。

6. デバッグモードの使用方法
	デバッグモードを有効にすることで、ゲーム内で様々なデバッグ用の操作が可能になります。
	デバッグモードを有効にすると、その回の獲得スコアが無効となります。
	各モードの起動方法は以下の通りです。
	・RShift + 1 : 無敵モードON/OFF
	・RShift + 2 : 武器性能最大化
	・RShift + 3 : 移動性能・HP最大化
	・RShift + 4 : プレイヤーのレベル +10
	・RShift + 5 : フィールド上の敵を全滅
	・RShift + 6 : フィールドの敵のHP +100
	・RShift + 7 : プレイヤーステータス初期化
	・RShift + 8 : 制限時間のカウントダウンON/OFF
	※デバッグモードのON/OFFはキーボードからのみ操作可能です。
